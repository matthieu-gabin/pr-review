PR review runs a Claude Code review of the pull request checked out in a workspace and shows what it found as proposed review comments on the diff, for you to edit, dismiss and post to GitHub as one review.

Every git workspace gets a Review button in its header. Its panel finds the open pull request of the checked-out branch, shows the pull request's diff, and a Run AI review button that starts a Claude agent in the workspace with the `/pr-review` skill. The skill reads the diff and the surrounding code, follows the repository's own review guides, and writes its findings to a file the panel reads: each one a comment anchored on a diff line, with a severity. You edit or dismiss them under the lines they point at, adjust the summary and the verdict, then post everything as one GitHub review. A finding on a line outside the diff goes into the review body.

Setup: the GitHub CLI (`gh`) signed in, and Claude Code available to Paseo. The plugin installs the skill at `~/.claude/skills/pr-review/SKILL.md` and keeps it up to date. Findings live in `~/.cache/pr-review/findings/`. The plugin writes to GitHub only when you press Post review.
